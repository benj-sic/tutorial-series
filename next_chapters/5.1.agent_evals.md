# Chapter 4: Evaluating Scientific Agents

Determine whether an agent performs a research task well, where it fails, and whether a change actually improves it.

Identify one agent-assisted taks from your own work.

- Define a scientific task and what success looks like.
- Create a set of representative and challenging test cases.
- Record and agent's final answers, tool calls, and supporting evidence.
- Evaluate correctness, evidence support, tool use, and uncertainty.
- Group failures by cause, revise the agent, and compare results across runs.

## 4.1 Define the task and success criteria

- Define: Research task, intended use, and consequences of an incorrect or unsupported answer

## 4.2 Build an evaluation set

- Cases that cover: ordinary requests, ambiguous questions, missing evidence, and situations where the agent should acknowledge uncertainty.

## 4.3 Run evaluations with Aviary

- Save final answers and trajectories (tool calls, observations, etc.)

## 4.4 Score answers and investigate failures

- Apply a rubric
- Write checks for observable requirements, e.g., whether agent used required tool, returned a valid ID, completed the task
- Examine indiviual cases / inspect failed trajectories to find root cause

## 4.5 Improve and rerun

- Revise prompt / tool / workflow based on observed failure and/or run the same eval with a different model
- Compare new results (quality, failure types, cost, time, etc.) with original run
